# How To Play — 2026-10-22 개편

공통: 파일철 배경, 큰 제목과 한 줄 부제, 가로 3행. 각 행은 왼쪽 번호·행동 설명 / 오른쪽 해당 예시. 본문은 27~38px, 제목 55px (1920×1080 기준). 실제 UI 예시는 기존 프리팹에서 분리한 편집 가능한 uGUI. 화면 예시는 현 게임 캡처이며 숫자·방향은 설명용 샘플.

| 페이지 | 제목 | 3단계 |
|---|---|---|
| 목표 | 가장 부유한 플레이어가 되세요! | $200으로 시작 → 자산 늘리기 → 13라운드 후 비교 |
| 조작 | 이동하고, 바라보고, E! | WASD 이동 → 대상 보고 E → Tab 내 정보 |
| 거래 | 주식 거래, 세 단계면 끝! | 창구 E → W/S 종류·A/D 수량 → 금액 확인 후 E |
| 경매 | 미래 정보를 입찰로 가져오세요! | 의자 E → 대상 확인 → A/D 금액·E 입찰 |
| 정보 | 얻은 정보로 다음 거래를 준비하세요! | Tab 수첩 → 라운드·방향 확인 → 마감 전 활용 |
| 베팅 | 가격이 내려가도 수익을 얻어요! | 베팅 탭 → 현재가 1주분 참가 → 종가 결과 |
| 결과 | 현금과 주식 가치를 더하세요! | 마지막 종가 → 현금·주식 합산 → 순위 |

각 페이지 [E] 자세한 규칙 +: 클릭 또는 E로 열기·접기. 본문의 3행 대신 세부 규칙 표시. Esc는 펼친 규칙부터 접고, 다시 누르면 HowToPlay 닫기. 페이지를 바꾸거나 다시 열면 기본 3행으로 복귀.

고정 내비게이션: A/W 이전 · D/S 다음 · Esc 닫기. 이전·다음·색인·닫기·규칙은 마우스 클릭 지원. 첫/끝은 순환하지 않음.

세부 규칙: 13라운드 / 일반 60초 / 경매 120초 (공개 60·비공개 30·거래 30), 2·6·10R 경매, 현금200, 공급 인원×5+5. 수량 순환·요청 전체 거절·동액 제출 우선·베팅 취소와 하한가·동점 처리 등은 접힌 내용에 보존.

2026-10-22 후속: 모든 페이지 제목 64px / 단계 제목 43px / 단계 본문 31px, Pretendard Black. 경매 1단계는 실제 의자와 조준점·E 안내를 1368×300 영역으로 잘라 685×150 전체 폭에 표시하며 별도 E키 영역 제거.
