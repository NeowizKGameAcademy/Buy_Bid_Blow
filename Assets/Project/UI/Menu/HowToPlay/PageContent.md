# HowToPlay 페이지 구성 초안

파일철 디자인: 짙은 청록색 서류철 표지, 황동 집게 하나, 겹친 아이보리 문서, 우측 색인 탭. 수첩의 고리 제본/연필 표 대신 인쇄된 안내 문서와 간단한 적색 밑줄. 글자는 향후 Unity Text, 실제 UI 예시는 별도 Image. 1920×1080, 중앙 문서, 좌 설명/우 실제 UI 확대. 외부 이미지 생성은 레이아웃 시안이며 문구 원본은 이 문서.
공통 조작: ← 이전 / → 다음 / Esc 닫기. 첫·끝 페이지는 순환하지 않고 경계 유지. 우측 색인은 현재 페이지 표시이며 마우스 조작 요구하지 않음. 현재/전체 페이지 표시. 각 페이지 3개 핵심 설명과 UI 예시.

## 01 목표와 경기 흐름
제목: 가장 많은 자산을 모으세요
- 현금 $200, 주식 0주로 시작합니다. 기본 3명, 최대 6명이 함께합니다.
- 총 17라운드. 일반 라운드 60초, 2·6·10·14라운드는 경매를 포함해 240초입니다.
- 라운드 동안 주가는 고정되고, 마감할 때 한 번 바뀝니다.
예시: 1→2 경매→3…17 타임라인, 현금+주식 평가액=총자산 그림. 거래·경매·베팅이 자산을 늘리는 수단임을 한 줄 안내.

## 02 조작과 화면
제목: 이동하고, 가까이에서 상호작용하세요
- WASD 이동 · 마우스 시점 · Space 점프.
- 창구·경매 의자를 바라보고 E로 이용합니다. Q로 닫거나 퇴석합니다.
- 왼쪽 위는 내 자산, 오른쪽 위는 라운드·시간입니다. 현재 주가는 거래소 시세판에서 확인합니다.
예시: 실제 탐색 화면과 번호 콜아웃. I 내 정보 수첩 · 수첩 ↑↓ 스크롤. 수첩/메뉴 키 안내 구분.

## 03 주식 거래
제목: 회사 창구에서 주식을 사고파세요
- Straw·Timber·Brick 창구에서 매수·매도를 선택합니다. 주식은 정수 단위로 거래합니다.
- 회사별 총 주식은 경기 시작 인원×4주. 매도하면 시장 재고로 돌아옵니다. 개인 매수 제한은 없습니다.
- 현금·재고·보유량이 부족하면 요청 전체가 거절됩니다. 입찰에 묶인 현금은 사용할 수 없습니다.
예시: 실제 거래창 LiveTrade.png의 Straw $16, 1주 구매 예시. 캡처 수량은 다음 요청량이며 왼쪽 자산은 구매 완료 후 상태임을 혼동하지 않게 패널만 발췌 사용. 핵심 안내: ↑↓ 메뉴 / ←→ 수량 / E 확인 / Q 닫기.
보조: 거래 수수료 없음 · 공매도 불가 · 경매 중에도 거래 가능.

## 04 정보 경매
제목: 정보를 두 가지 방식으로 낙찰받으세요
- 경매 라운드 시작과 동시에 공개 경매 60초, 이어서 비공개 경매 60초가 진행됩니다.
- 공개: 최고 입찰보다 $1 이상 높게 제출합니다. 최고 입찰은 취소할 수 없고, 낙찰자·낙찰가는 공개됩니다.
- 비공개: 마감 전 수정·취소 가능. 같은 금액이면 현재 금액을 먼저 제출한 사람이 우선입니다. 금액을 바꾸면 우선순서도 갱신됩니다.
예시: 실제 경매 화면, 공개/비공개 비교 카드. 비공개는 본인 낙찰 성공·실패만 확인. 입찰금은 예약되며 낙찰 시 차감, 탈락/취소 시 해제. 퇴석은 입찰 취소가 아님. 무입찰 유찰 · 연장 없음. 최소 입찰가 미확정이므로 안내에 숫자 고정하지 않음.

## 05 정보와 수첩
제목: 구매한 정보로 다음 종가를 예상하세요
- 한 상품은 두 라운드, 라운드마다 서로 다른 두 회사의 방향 정보를 담습니다. 회사 조합은 라운드마다 무작위입니다.
- 경매에 오르면 대상 라운드·회사가 공개되지만, 상승·하락·보합은 낙찰자만 확인합니다.
- I로 수첩을 열고 ↑↓로 확인합니다. 빈칸은 미보유 정보입니다. 다른 사람에게 말하거나 거짓 정보를 말할 수도 있습니다.
예시: 실제 LiveNotebook.png. '5R 하락'은 4R 종가→5R 종가의 하락이며 구매 당시 가격과의 비교가 아님. 개최별 대상 2~5 / 6~9 / 10~13 / 14~17을 짧게 보조 표시.

## 06 하락 베팅
제목: 주식이 없어도 하락에 베팅할 수 있어요
- 각 회사 창구에서 현재 주가 1주분을 내고 해당 라운드의 하락에 베팅합니다. 동시에 유지할 수 있는 베팅은 하나입니다.
- 실제 종가가 하락하면 참가금 포함 2배 지급. 상승·보합이면 참가금을 잃습니다.
- 라운드 마감 전 취소하면 전액 환불되며 다시 참여할 수 있습니다. 현재가가 하한 $5이면 참여할 수 없습니다.
예시: $40 참가 → 하락 $80 / 상승·보합 $0. 주식 보유와 독립. 선택 회사 베팅/취소 UI 예시는 별도 캡처 필요.

## 07 종료와 순위
제목: 마지막 종가까지 확인하세요
- 17라운드의 주가 변경과 베팅 정산이 끝나면 최종 점수를 계산합니다.
- 최종 점수 = 보유 현금 + 각 회사 보유 주식×최종 주가. 주식을 미리 매도할 필요는 없습니다.
- 점수가 같으면 총 보유 주식 수가 많은 사람이 앞섭니다. 이것도 같으면 공동 순위입니다.
예시: 현금 $80 + Straw 2주×$30 + Timber 1주×$40 = $180. 마지막 요약 '거래 · 정보 · 베팅을 조합하세요'.

## 제작 순서
내용 검토 → 거래 페이지 대표 시안 → 공통 파일철 배경/집게/색인 자산 → 7페이지 실제 UI 캡처 정리 → 편집 가능한 글자로 Unity 조립 → 키보드 전환/메인 메뉴 연결 → 해상도·문구 검수.
7페이지 패널을 SC_MainMenu에 통합. 글자·예시·페이지·인덱스는 각각 편집 가능한 컴포넌트. ←→ 전환, Esc 닫기, 닫을 때 HowToPlay 버튼으로 포커스 복귀.
