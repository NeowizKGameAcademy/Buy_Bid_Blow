# HowToPlay 스프라이트 요구사항

제작: imagegen 기본 내장 도구. 투명 PNG, 문자 없음. 글자는 Unity Text 컴포넌트로 편집.

|순서|파일|요구사항|
|---|---|---|
|1|BG_DossierFolder|짙은 청록 파일철, 황동 모서리, 정면, 중앙 여백|
|2|BG_DossierPaper|겹친 아이보리 문서, 옅은 종이 질감, 넓은 빈 영역|
|3|DEC_DossierClip|상단 황동 문서 클립, 투명 외곽|
|4|TAB_Dossier|청록 가죽 인덱스, 스티치, 글자 없음|
|5|TAB_DossierSelected|같은 형태, 밝은 아이보리·황동으로 선택 구분|
|6|TAB_DossierDisabled|같은 형태, 저채도 어두운 청록 예비 비활성 상태|

배경·종이·탭은 9-slice, 클립은 비율 유지. 원본 PNG와 알파 여백을 제외한 Sprite asset을 함께 유지. 탭은 진행 순서와 무관하게 모두 접근 가능하므로 비활성 탭은 예비 자산이며, 첫/마지막 페이지에서는 하단 이전/다음 안내만 어둡게 표시.

실제 UI 예시는 Examples의 별도 이미지로 배치. 설명 문구와 페이지 제목·숫자는 이미지에 굽지 않음.
