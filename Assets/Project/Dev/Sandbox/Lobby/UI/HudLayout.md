# 로비 HUD 배치

대상 씬: `Assets/Project/Dev/Sandbox/Lobby/SC_Lobby.unity`.
기준: 1920×1080, 좌측 위가 (0,0). Canvas는 Screen Space Overlay, CanvasScaler는 Scale With Screen Size / 너비 기준입니다.

| 요소 | 좌측 위 X,Y | 크기 | 고정 기준 |
|---|---|---|---|
| 로고판 | 48,30 | 450×120 | 좌측 상단 |
| 부제판 | 133,129 | 280×44 | 좌측 상단 |
| 인원 | 1438,40 | 132×58 | 우측 상단 |
| 옵션 | 1587,40 | 130×58 | 우측 상단 |
| 나가기 | 1733,40 | 144×58 | 우측 상단 |
| 준비 완료/취소 | 1522,940 | 350×92 | 우측 48 / 아래 48 |

카메라 위치는 (0,3.3,-0.4), 주시점은 (0,1.6,-10.1), 16:9 수직 화각 48°입니다. 기존 발코니 아래를 보며 양쪽 기둥을 포함합니다. 화면비가 좁아지면 수직 화각을 넓혀 여섯 자리의 가로 구도를 유지합니다.

캐릭터 자리 i(0~5)는 `((2.5-i)×2.1, 0.04, -10.1)`입니다. 카메라가 -Z 방향을 보므로 +X가 화면 왼쪽입니다. 캐릭터 배율은 1.5, 루트 회전은 Y=180°이며 루트 모션은 꺼집니다.

## 캐릭터를 따라가는 요소

캐릭터 기준점 `자리 + (0,3,0)`을 `Camera.WorldToViewportPoint`로 투영하고 Canvas 좌표로 변환합니다. 다음 값은 해당 점에서의 오프셋이며 Y 양수가 화면 위입니다.

| 요소 | 위치 / 크기 |
|---|---|
| 내 이름표 중심 | 기준점에서 위 136px / 176×40 |
| 다른 이름표 중심 | 기준점에서 위 24px / 176×40 |
| 상태 배지 | 이름표 중심에서 아래 43px / 150×34 |
| 방장 왕관 | 이름표 중심에서 위 30px / 29×29 |
| ‘나’ 배지 | 이름표 중심에서 오른쪽 94px, 아래 22px / 34×34 |
| 세로 선택기 중심 | 기준점에서 위 16px / 선택 강조 146×32 |
| 항목 행 | 선택기 중심에서 위31 / 0 / 아래31px |
| 위·아래 안내 | 선택기 중심에서 위·아래51px |
| 키캡 | 선택기 오른쪽95px / 위14, 아래14px |
| 좌·우 화살표 | `자리+(0,1.55,0)` 투영점에서 좌·우104px / 54×54 |
| 빈 자리 표시 | `자리+(0,1.45,0)` 투영점 / 126×126 |
| 발밑 선택 링 | 자리 Y에서 +0.02 / 수평 평면 2×2m |

로고와 이름표, 상태와 선택기, 선택기와 귀가 겹치지 않도록 위 간격을 적용했습니다. 반투명 선택기는 내 캐릭터에만 표시됩니다. 하단 패널은 없습니다.

## 조작

- H: 호스트 시작. J: 접속 주소 입력, Enter: 접속, Esc: 주소 입력 종료.
- ↑↓: 상의/하의/넥타이 순환 선택. ←→: 해당 항목 변경.
- Enter / Space: 준비 완료·취소. Tab: 준비 → 옵션 → 나가기 포커스 순환.
- O: 옵션 열기·닫기. 옵션에서 ↑↓ 행 선택, ←→ 음량 변경, Enter 전체화면 전환 또는 닫기.
- Esc: 옵션 닫기, 접속 중이면 나가기.

`Lobby Art Preview - Editor Only`의 늑대 네 마리는 씬 편집용 전시 모델입니다. 플레이 시작 때 제거하며, 네트워크 참가자로 사용하지 않습니다. 플레이에서는 실제 접속 인원과 준비 상태를 표시합니다.

재배치 메뉴: `Tools > BuyBidBlow > Lobby > Apply Sprite HUD`. 씬에 저장된 HUD 자식 오브젝트를 편집할 수도 있으며 메뉴를 다시 실행하면 HUD 배치를 재생성합니다. 원본 AuctionHall-Deco 씬에는 적용하지 않습니다.
