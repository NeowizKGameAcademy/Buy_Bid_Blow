# UI Showcase 사용법

`SC_UIShowcase.unity`를 열고 Play하세요. 실제 서버·호스트 접속 없이 표시 상태와 입력을 확인하는 Dev 전용 씬입니다. 실행용 UI 자산은 `Assets/Project/UI`의 각 오브젝트 폴더에 있습니다. 실제 실행 씬과 Build Settings에는 연결하지 않았습니다.

|키|동작|
|---|---|
|PageUp / PageDown|이전 / 다음 표시 상태|
|Home|첫 오류 팝업|
|F5|현재 화면 다시 열기|
|F6|거래 요청 실패 로그 추가|
|F7|로비 입장 로그 추가|
|방향키|팝업 버튼 선택 / 설정 항목과 값 조절|
|Enter|선택한 동작 요청|
|Esc|닫기·안전 취소. 끊김·최종 결과는 복귀 버튼 사용|

21개 상태: 공통 오류, 접속 4상태, 게임 메뉴, 나가기 확인, 로딩 2상태, 결과 3명·6명 공동 우승, 라운드 시작, 공개 낙찰, 비공개 성공·실패, 유찰, 거래·베팅 로그, 로비 로그, 설정, 조작 안내, 긴 오류 원인.

버튼은 실제 게임 동작 대신 하단에 요청 내용을 표시합니다. 설정은 값 조절·적용 요청·미적용 변경 취소까지 검증하며 기기의 화면·소리·감도를 바꾸거나 저장하지 않습니다. 결과는 서버가 확정한 표 데이터를 받는 표시 전용입니다. 실제 랭킹 계산·거래·접속·로딩 로직은 포함하지 않습니다.

공통 프레임은 기존 PremiumSprites 이미지를 UI/Shared/Modal/Art로 복사해 재사용했고, 버튼은 기존 UI/Menu의 4상태 스프라이트를 사용합니다. 글자·Image·색상·앵커는 모두 편집 가능합니다. 프리팹에는 Canvas가 없으므로 사용할 Canvas 하위에 넣습니다.

통합 담당자는 `Assets/Project/UI/Shared/UIIntegration.md`를 읽어주세요. 호출 API, 버튼 인덱스, 필요한 서버 데이터, 개인정보 표시, 입력 중복 방지, 이동 차단, 접속 상태 연결점을 정리했습니다.

검증 자료:
- BuildVerification.txt: 프리팹과 시안 캡처 생성
- PlayVerification.txt: 키보드 입력·표시 상태·로그 대기열·자동 닫힘 검사
- LayoutAudit.txt: 1920×1080, 1366×768, 1280×800 전 상태 렌더·텍스트 높이·Dev 의존성 검사
- Previews: 전체 상태별 1920×1080 캡처
- AuditPreviews: 작은 해상도의 메뉴·결과·설정 캡처

Tools > Buy Bid Blow > UI 아래 Build / Verify / Audit 메뉴가 있습니다. Build는 생성 프리팹과 실험 씬을 재작성하므로 수동 편집 이후에는 주의하세요. 테스트 씬을 배포 씬 목록에 추가하지 마세요.
