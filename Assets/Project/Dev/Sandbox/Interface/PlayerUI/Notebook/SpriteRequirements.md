# 정보 수첩 스프라이트 제작 명세

기준 시안: 거친 색연필·연필 표, 낮은 명도의 적갈색 상승/청색 하락. 가죽 표지와 황동 제본 유지.
1920×1080 기준 수첩 약 980×900, 중앙보다 오른쪽. 17라운드×3회사 슬롯, 8개 행 표시, 키보드 스크롤.

공통: PNG 실제 알파, 매트/체커보드 배경 금지, 글자는 스프라이트에 포함하지 않음. Sprite Single, alphaIsTransparency, Mipmap Off, 압축 없음. 고리/아이콘은 비율 유지. 배경·칸 테두리만 9-slice. 조작은 키보드만 사용하며 마우스 버튼 상태 스프라이트는 필요 없음.
빈칸은 실제 미보유 정보이며 질문표/임의 방향을 넣지 않음. 방향은 화살표+문구+색을 함께 표시. 지난 행은 상태 글자와 농도 변경, 현재 행은 밑칠+책갈피로 구분.
제목·회사명·라운드·방향·안내·페이지 범위는 편집 가능한 일반 Unity Text로 조립. 밑칠과 값은 별도 Image/Text. 스크롤 위치는 native UI로 만들고 연필선 스프라이트를 재사용.
