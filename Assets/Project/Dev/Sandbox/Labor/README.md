# 회사 작업장 테스트

`LaborSandbox.unity`를 열고 Play → 로컬 호스트 시작 → 준비 완료 → 경기 시작 · 인트로 생략.
기존 거래소, 캐릭터, 주식 거래, 정보 경매, 뽑기머신을 함께 사용합니다.
일반 라운드 90초, 경매 라운드 150초입니다.

- 로비 금색 문을 바라보고 **E**: 작업장 이동. 작업장 EXCHANGE 문에서 E: 거래소 복귀.
- 회사 블록/폭탄을 바라보고 **E**: 들기. 같은 회사 통을 보고 E: 투입. 폭탄은 어느 회사든 가능.
- **G**: 들고 있는 물건을 원위치에 반납. 문 이동, 라운드 전환, 연결 종료, 45초 경과에도 회수됩니다.
- 일반 블록: 현재 주가의 20% 버림(최소 $1) 즉시 지급, 해당 회사 이번 라운드 주가 보정 +$1.
- 폭탄: 무급, 해당 회사 주가 보정 -$3.
- 개인별 라운드 한도: 급여 5회, 폭탄 1회. 투입한 물건은 해당 라운드에서 소모되며 다음 라운드 시작에만 새로 배치됩니다.
- 회사별 보정은 원시 합산 후 ±$5 제한. 상승/하락/보합 방향과 하한가를 유지합니다.
- 급여, 소유권, 거리, 회사 일치, 중복 투입, 라운드 한도는 서버 검증입니다.

임시 작업장 형상은 LaborRoom이 실행 시 생성합니다. 씬에는 문 좌표와 작업장 위치가 저장됩니다.
왕복은 별도 작업장으로 순간이동하는 방식입니다. 기존 로비 외형과 충돌 구조는 유지합니다.
매 라운드 서버가 회사별 블록 1~5개, 폭탄 전체 1~2개를 무작위 배치합니다. 모든 플레이어가 공유하며 남은 물건도 다음 라운드에 교체됩니다.

검증: EditMode LaborTests / ContributionPriceTests, PlayMode LaborSandboxTests.
