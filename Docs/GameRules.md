# BUY, BID, BLOW — 현재 게임 규칙

기준일: 2026-10-14. 사용자가 합의한 최신 규칙이다. GameDesign.md의 초기 제안 및
Decisions.md의 과거 게임 규칙과 충돌하면 이 문서를 우선한다. 구현 완료를 뜻하지 않는다.

## 인원·목표·시작

- 최소 시작 3명, 기본 3명, 최대 6명이다.
- 시작 현금은 현재 플레이테스트 기준 $200이다. 시작 주식은 0주다.
  회사는 Straw / Timber / Brick이다.
- 17라운드 종료 후 현금 + 각 회사 보유 주식 수 × 최종 주가의 합으로 순위를 매긴다.
- 총자산이 같으면 전체 회사의 보유 주식 수 합이 많은 플레이어가 앞선다.
  보유 주식 수도 같으면 동순위이며, 공동 1위는 공동 우승이다.

## 라운드

- 총 17라운드. 일반 라운드는 60초, 2·6·10·14라운드는 경매 라운드로 240초다.
- 기본 경기 시간은 29분이다. 정산·전환 시간은 별도다.
- 라운드 중 가격은 고정되며 매 라운드 마감에 한 번 변동한다.
- 마감 시 거래를 중단하고 변동을 적용한다. 보유 주식은 다음 라운드로 유지한다.
- 거래·입찰·베팅 및 취소 요청은 서버 처리 순서를 기준으로 판정한다.
  서버에서 처리하는 시각이 해당 행동의 마감 시각 이상이면 거절한다.
  경매는 해당 경매 마감, 거래·베팅은 해당 라운드 마감을 적용한다.

## 가격

모든 정수 난수 범위는 양 끝을 포함한다. 회사마다 독립적으로 추첨한다.
초기 주가는 무작위 20~30 + 회사별 무작위 보정이다.

| 회사 | 초기 보정 | 가능한 초기 주가 | 변동폭 보정 | 최종 변동폭 A | 상승 / 하락 |
|---|---|---|---|---|---|
| Straw | -8~-5 | $12~25 | +2~+5 | 4~12 | 60% / 40% |
| Timber | -1~+1 | $19~31 | 0~+1 | 2~8 | 70% / 30% |
| Brick | +5~+8 | $25~38 | -2~-1 | 1~6 | 80% / 20% |

- 변동폭 A = max(1, 무작위 2~7 + 회사별 보정). 방향은 별도로 추첨한다.
- 상승은 +A, 하락은 -A. 가격 하한은 $5이며 실제 종가는 max(5, 직전 주가 + 추첨 변동)이다.
- 거래량은 가격에 영향을 주지 않는다. 판매된 미래 정보는 실제 결과와 일치해야 한다.
- 방향 정보는 실제 종가와 직전 종가를 비교해 상승·하락·보합으로 표시한다.
  하한 보정으로 가격이 그대로이면 추첨 방향이 하락이어도 정보는 보합이다.

## 유한 주식 공급·시장

- 회사별 총량은 현재 플레이테스트 기준으로 경기 시작 인원 × 4주를 적용한다.
  3명이면 회사별 12주, 6명이면 회사별 24주다. 총량은 경기 시작 시 고정한다.
- 개인 매수 한도는 없다. 시장 전체 공급과 사용 가능한 현금 범위에서 매수한다.
- 1층 회사별 창구에서 거래한다. 경매 진행 중에도 거래할 수 있다.
- 수수료와 공매도는 없다. 현금과 보유 주식은 본인만 확인한다.
- 다른 플레이어의 이동과 창구 이용은 관찰할 수 있다.
- 매도한 주식은 시장 재고로 반환한다. 추가 발행은 없으며 인원 변동으로 총량을 다시 계산하지 않는다.
- 주식은 정수 단위로 거래한다.
- 재고 또는 사용 가능한 현금이 요청 수량을 충족하지 못하면 매수 요청 전체를 거절한다.
  일부 체결하지 않으며, 현재 재고와 사용 가능한 현금을 반영한 구매 가능 수량을 표시한다.

## 경매

주식 묶음 경매와 Dutch는 사용하지 않는다. 상품은 정보만 판매한다.
각 경매 라운드에 상품 두 개를 다음 순서로 판매한다.

| 경과 시간 | 진행 |
|---|---|
| 0~60초 | 1차 공개 경쟁 입찰 |
| 60~120초 | 2차 비공개 금액 제출 |
| 120~240초 | 경매 없이 거래·이동 |

- 공개 경매는 현재 최고가보다 $1 이상 높이면 유효한 인상이다. 최소 입찰가는 미정이다.
- 공개 경매의 현재 최고 입찰은 입찰자가 취소할 수 없다.
- 비공개 경매는 마감 전 입찰 금액을 수정하거나 취소할 수 있다. 취소 시 예약금을 해제한다.
- 동액은 현재 금액을 먼저 제출한 사람이 우선한다. 금액을 수정하면 우선 시각도 갱신한다.
- 입찰금은 예약되어 다른 거래에 사용할 수 없다.
- 공개 경매에서 최고 입찰자가 바뀌면 이전 최고 입찰자의 예약금을 해제한다.
- 낙찰 시 예약금을 차감하고 정보를 지급한다. 비공개 경매 패찰자의 예약금은 해제한다.
- 연장은 없으며 무입찰이면 유찰한다.
- 공개 경매의 낙찰자·낙찰가는 공개한다. 정보 내용은 낙찰자만 확인한다.
- 비공개 경매는 각 플레이어에게 본인의 낙찰 성공·실패만 알려준다.
  낙찰자·낙찰가·다른 플레이어의 결과는 공개하지 않는다.

## 정보 상품

- 한 상품은 서로 다른 두 대상 라운드의 정보를 담는다.
- 각 대상 라운드마다 서로 다른 회사 두 곳의 상승·하락·보합을 알려준다.
  따라서 상품 하나에 두 라운드 × 두 회사, 총 네 개의 방향 정보가 담긴다.
  변동폭과 정확한 금액은 판매하지 않는다.
- 회사는 대상 라운드마다 세 회사 중 서로 다른 두 회사를 무작위로 선정한다.
  서로 다른 대상 라운드끼리는 같은 회사 또는 같은 회사 조합이 다시 나오는 것을 허용한다.
  이전의 진행자 돼지 회사 고정 규칙은 대체한다.
- 경매에 올라올 때 대상 라운드와 회사를 공개한다. 예: `3R/Straw·Timber, 5R/Timber·Brick`.
  실제 상승·하락·보합 내용은 낙찰자만 확인한다.
- “4라운드 하락”은 3라운드 종가보다 4라운드 종가가 낮다는 뜻이다.
- 각 개최의 네 대상 라운드를 무작위로 두 개씩 나눈다. 두 상품의 대상 라운드는 겹치지 않는다.

| 개최 라운드 | 전체 정보 대상 | 정보 기준가 |
|---|---|---|
| 2 | 2·3·4·5 | $20 |
| 6 | 6·7·8·9 | $25 |
| 10 | 10·11·12·13 | $30 |
| 14 | 14·15·16·17 | $35 |

기준가의 최소 입찰가 적용 여부는 미정이다.

## 하락 베팅

- 플레이어마다 한 라운드에 최종 유지하는 베팅은 회사 하나에 한 건이다.
- 라운드 시간 내 취소하면 참가금을 전액 환불하며, 같은 라운드에 다시 참여할 수 있다.
- 참가금은 선택한 회사의 현재 주가 1주분이다.
- 해당 라운드에 회사 주가가 하락하면 참가금 포함 총 2배를 지급하고, 실패하면 전액 손실이다.
- 현재 주가가 하한 $5인 회사에는 베팅할 수 없다.
- 각 회사의 거래 창구에서 해당 회사의 하락 베팅에 참여하거나 취소한다.
- 거래·경매 예약금과 베팅 정산의 세부 처리 순서는 추가 결정한다.

## 공유·블러핑

말로 정보 공유와 거짓말을 할 수 있으며, 이동·창구 방문으로도 상대를 속일 수 있다.
타인이 말한 정보의 진위를 시스템으로 인증하지 않는다.

## 남은 결정

1. 현재 플레이테스트 기준인 시작 현금 $200과 회사별 공급 배수 4의 밸런스 검증.
2. 최소 입찰가와 정보 기준가의 역할(사용자 요청으로 미정 유지).
3. 낙찰금 산정 방식, 명시적 패스 기능, 동일 금액 재제출 시 우선 시각 처리.
4. 거래·경매 예약금과 베팅 정산의 세부 처리 순서 및 접속 이탈 처리.

## 현재 구현 범위

MatchSettings에는 인원, 회사별 초기 공급 계산, 시작 자산, 라운드 시간과 경매 일정,
가격 범위·확률·하한을 반영했다. 경매 판정·거래 재고·하락 베팅·최종 순위는 이 문서로
규칙을 기록한 상태이며, 이번 변경에서 실행 시스템을 구현한 것은 아니다.
