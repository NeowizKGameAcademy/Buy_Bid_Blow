# BUY, BID, BLOW 게임 기획

> 정보를 사고, 미래에 투자하는 늑대들
> 정보 경매 × 주식 투자 × 1인칭 멀티플레이 파티게임

발표 기획서 V2(16장)와 발표자 노트를 옮긴 문서다. 수치와 사양은 초기 프로토타입 제안값이며, 원본의 화면 이미지는 모두 ImageGen 콘셉트 목업이라 옮기지 않았다. 구현 세부 결정은 [Decisions.md](Decisions.md)를 따른다.

## 1. 게임 콘셉트

- 미래의 주가 변동은 이미 정해져 있다. 플레이어는 그 결과를 모른 채 시작한다.
- 경매로 정보를 사고, 시장에서 주식을 거래한다.
- 마지막에 가장 많은 자산을 가진 늑대가 승리한다.
- 구현상으로는 라운드마다 숨겨진 변동을 결정하며, 각 라운드 결과는 거래 시작 전에 확정한다. 거래량은 결과에 영향을 주지 않는다.

## 2. 메인 메뉴

- 게임 진입 화면에서 플레이 시작, 방 생성과 참가, 설정 및 종료를 고른다.
- 거래소 외관과 주변 지형으로 게임 분위기를 전달한다.

## 3. 멀티플레이 로비

- 4인 준비 화면에서 참가자와 준비 상태를 확인한다.
- 넥타이 색상을 선택한다.
- 방 코드로 친구를 초대한다.
- 모두 준비하면 게임을 시작한다.

## 4. 세계관과 세 회사

돼지 삼형제는 회사를 운영하고, 늑대들은 투자자가 된다.

| 회사 | 사업 테마 | 대표 컬러 |
|---|---|---|
| Straw Corp | 짚 / 경량 건축 | 노랑 · 베이지 |
| Timber Works | 목재 / 제조업 | 초록 · 갈색 |
| Brick Holdings | 벽돌 / 건설·부동산 | 빨강 · 적갈색 |

초기에는 세 회사에 동일한 규칙을 적용한다. 회사별 특수 능력은 초기 범위에서 제외한다.

## 5. 핵심 재미

| 요소 | 내용 |
|---|---|
| 정보의 가격 | 정보를 사면 미래가 보이지만, 투자할 현금이 줄어든다 |
| 정보의 조합 | 변동폭과 방향을 함께 알면 정확한 결과를 추론한다 |
| 상대의 행동 | 낙찰자의 이동을 보고 정보 없이 투자할 수도 있다 |
| 블러핑 | 거래소 방문과 말로 상대의 판단을 흔든다 |

정보를 가진 늑대의 이동도 판단의 단서가 된다. 공개 알림은 정보 소유자만 표시하고, 자산과 거래 내역은 드러내지 않는다.

## 6. 전체 게임 루프

100초 동안 경매와 거래가 동시에 열린다.

1. **시장 오픈** — 이동과 거래 시작
2. **경매 알림** — 참여 여부 결정
3. **정보 입찰** — 낙찰자만 내용 확인
4. **시장 이동** — 정보와 행동 관찰
5. **매수 / 매도** — 다음 경매와 거래 반복
6. **Closing Bell** — 가격 변경과 결과 공개

일정 예시: 남은 100초 오픈 / 80초 경매 #1 / 45초 경매 #2 / 0초 마감

## 7. 공간과 이동

- 하나의 건물 안에 있는 두 공간(거래 창구와 경매장)을 1인칭으로 직접 오간다.
- 이동에 약 5초가 걸린다. 거래를 계속할지, 곧 열릴 경매로 갈지 시간까지 계산한다.
- 시장과 경매는 동시에 열리고 자유롭게 이동한다. 콘셉트 화면의 Phase 표시는 실제 규칙이 아니다.

## 8. 정보 시스템

| 정보 | 공개 내용 | 예시 |
|---|---|---|
| Analyst Report | 변동폭만 공개 | Straw ±6 / Timber ±4 / Brick ±2 |
| Insider Memo | 방향만 공개 | Straw 상승 / Timber 하락 / Brick 상승 |
| 두 정보를 조합한 결과 | — | Straw +6 / Timber −4 / Brick +2 |

- 정보 내용은 낙찰자만 확인한다. 낙찰자의 신원은 모두에게 공개한다.
- 정보 종류와 경매 방식은 라운드마다 무작위로 조합한다.

## 9. 정보 경매

| 방식 | 진행 | 낙찰 |
|---|---|---|
| Open | 공개 경쟁 입찰 | 최고가가 낙찰 |
| Secret | 비공개 금액 제출 | 동시 공개 후 최고가 낙찰 |
| Dutch | 가격이 점차 하락 | 먼저 구매하면 즉시 낙찰 |

**비공개 입찰 화면 (Secret)**
- 개인 입찰 금액을 조절한다.
- 제출 또는 패스한다.
- 상대의 제출 상태를 확인한다.
- 입찰 금액은 마감 후 동시에 공개한다.

**더치 경매 화면 (Dutch)**
- 시간에 따라 정보 가격이 하락한다.
- 현재 가격으로 즉시 구매한다.
- 기다리면 가격이 낮아지지만 상대가 먼저 낙찰받을 수 있다.

## 10. 주식 거래 규칙

- 라운드 중 가격은 고정된다. 거래량이 가격에 영향을 주지 않는다.
- 창구에서 거래한다.
- 현금과 보유 주식은 비공개다. 다른 플레이어는 거래소 방문만 관찰할 수 있다.
- 주식은 라운드 사이에 유지된다.
- 초기에는 공매도를 제공하지 않는다. 대신 회사별로 2주를 지급해 하락 정보로 손실을 회피할 수 있게 한다.

## 11. 한 라운드 플레이 예시

| 단계 | 내용 |
|---|---|
| 시작 | 현금 $100 |
| 정보 구매 | 두 정보에 총 $30 지출 가정, 남은 투자금 $70 |
| 결과 추론 | Straw ±6과 상승 방향을 함께 알면 +6을 예상 |
| 투자 판단 | 현재가 $20에서 3주 매수, 현금 $10 잔여 |
| 상대 관찰 | 다른 플레이어는 Straw 방문을 보고 따라가거나 의심 |

초기 보유 주식의 가치는 별도로 유지한다. 추가 매수 3주의 평가이익은 $18이므로 이 종목 거래만으로는 정보 비용 $30을 회수하지 못한다. 정보 가치는 다른 종목의 이익과 손실 회피까지 함께 고려한다.

## 12. Closing Bell과 승리 조건

마감과 동시에 거래를 멈추고, 숨겨진 변동을 적용한다.

| 회사 | 시작가 | 변동 | 새 가격 |
|---|---|---|---|
| Straw | $20 | +$6 | $26 |
| Timber | $25 | −$4 | $21 |
| Brick | $30 | +$2 | $32 |

- 다음 라운드는 새 가격에서 시작하며, 새로운 숨겨진 변동을 결정한다.
- 최종 총자산 = 현금 + 보유 주식의 최종 평가액
- 6라운드 종료 후 총자산 1위가 승리한다.

## 13. 초기 프로토타입 범위

| 항목 | 제안 사양 |
|---|---|
| 플레이 구성 | 4명 / 3개 회사 / 6라운드 |
| 시간과 경매 | 라운드 90~100초 / 정보 경매 2회 |
| 초기 자산 | 현금 $100 / 회사별 주식 2주 |
| 정보와 입찰 | 변동폭·방향 / Open·Secret·Dutch |
| 구현 범위 | 1인칭 이동 / 비공개 포트폴리오 / 음성채팅 권장 |

**검증할 플레이 경험**
- 정보 없이도 관찰로 경쟁할 수 있는가?
- 정보 비용과 이동 시간이 의미 있는 선택을 만드는가?

재미와 밸런스는 플레이테스트로 확인한다.

## 원본 기획서의 참고 사항

- 콘셉트 이미지 일부에서 다른 플레이어의 현금이 보인다. 비공개 자산 규칙에 맞춰 후속 UI에서 조정해야 한다.
- 콘셉트 화면의 UI 언어는 영어이며, 화면 수치는 모두 예시다.
