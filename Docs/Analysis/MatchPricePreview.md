# 17라운드 주가 미리보기 (2026-10-13)

> 이전 하한 $1을 사용한 분석 기록이다. 이후 확정된 하한은 $5이며 현재 설정과 Unity 미리보기에는 $5가 적용된다. 최신 규칙은 [GameRules.md](../GameRules.md)를 따른다.

새 합의 중 가격 미리보기에 필요한 설정을 반영했다.

- 17라운드 / 일반 라운드 60초
- 2·6·10·14라운드는 240초, 각 경매는 60초
- 기본 경기 시간 1,740초(29분), 정산·전환 시간 제외
- 초기 현금 100 / 초기 주식 0
- 기존 초기 주가 범위, 회사별 보정, 변동폭 및 상승 확률 유지

경매 시작 시각은 미확정이므로 AuctionSlots는 빈 배열이다. 이는 경매가 없다는 뜻이
아니라 경매 라운드 내 세부 시작 시각이 아직 없다는 뜻이다.
AuctionRounds, AuctionRoundSeconds, AuctionDurationSeconds로 개최 라운드와 시간을 표현한다.
서버 Match와 경매 실행 로직은 아직 구현하지 않았다.

최저 주가도 미확정이다. 이번 분석만 기존 MinPrice=1을 임시 적용했다.
하한에 닿으면 추첨 변동과 실제 적용 변동이 다르므로 CSV에 둘 다 남겼다.
하락했지만 주가가 그대로인 경우의 정보 표현 및 베팅 판정은 아직 확정하지 않았다.

## 확인 방법

Unity 메뉴 Tools > BuyBidBlow > Preview Price Changes에서 전체 경기 그래프와
라운드별 종가/적용 변동을 확인한다. 같은 Seed는 같은 경기 결과를 재현한다.
Reload / Replay는 현재 JSON을 다시 읽는다. New Seed는 다른 경기 예시를 만든다.
표의 raw 표시는 하한 보정 전 추첨 변동이다. CSV로 원시·적용 변동을 함께 저장할 수 있다.

## 예시와 검사

Seed 20261013: 시작 가격 Straw 20 / Timber 25 / Brick 33,
17라운드 종가 Straw 5 / Timber 68 / Brick 70.
세부 결과는 MatchPrices-20261013.csv를 참고한다.

실제 Systems C# 소스와 동일한 미리보기 계산 소스를 컴파일해 검사했다.
5개 시드의 재현성, 17회 마감, 경매 개최 라운드, 1,740초 합계, 가격 하한을 확인했다.
시드 0~999의 1,000경기에서 평균 최종 주가는 23.88 / 38.96 / 49.10이었다.
그중 422경기는 한 번 이상 하한에 의해 변동이 보정되었다.
이는 현재 임시 하한을 적용한 난수 표본이며 확정 밸런스나 가격 예측이 아니다.

이 변경은 주가 미리보기와 관련 설정만 다룬다. 비공개 경매 공개 정책, 정보 상품,
하락 베팅, 공급 한도 등 나머지 규칙은 이번에 구현하지 않았다.
