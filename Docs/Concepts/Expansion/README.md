# Buy Bid Blow — 콘텐츠 확장 시안

여섯 아이디어를 검토하기 위한 제안이며, 구현 완료 기능이나 확정 규칙을 뜻하지 않습니다. 수치와 효과는 플레이 테스트로 조정합니다.

## 1. 부동산 집문서
- 역할: 큰 자금을 투자해 반복 수입을 얻는 종결급 아이템.
- 흐름: 중반 이후 한정 경매 → 집문서 획득 → 정해진 라운드에 임대료 지급 → 최종 자산 정산.
- 초기안: 1인 1개, 획득 직후가 아닌 다음 지급 시점부터 수익 발생. 최종 매각 가치와 누적 임대료를 함께 조정.
- 핵심 선택: 안정 수입을 얻는 대신 주식과 정보 입찰에 쓸 현금이 줄어듦.
- 주의: 먼저 산 사람이 자동으로 승리하지 않도록 남은 지급 횟수 대비 가격을 검토. 후반에도 구매 이유가 있는 잔존 가치 필요.

## 2. 청산 메커니즘
- 역할: 자금 관리 실패에 실제 결과를 부여.
- 전제: 현금 0만으로는 청산 이유가 부족함. 대출 원리금이나 사전에 공개된 납부 의무가 있어야 함.
- 초기안: 한도 내 선택 대출 → 만기 안내 → 자율 상환 → 미상환 시 보유 자산 일부 강제 매각.
- 핵심 선택: 빌린 돈으로 투자 기회를 늘리는 대신 만기 위험 부담.
- 주의: 주식 전액 현금 매수만 가능한 현재 구조라면, 가격 하락만으로 추가 부채가 생기지는 않음. 자산 처분 순서와 가격을 미리 공개하고 탈락보다 거래 재개를 목표로 설계.

## 3. 파티 아이템 상점
- 역할: 현금을 수익 외의 견제와 방어에도 사용.
- 초기안: 목줄로 잠시 이동 범위 제한, 해제 도구로 대응. 보유 개수 제한과 재사용 대기시간 적용.
- 핵심 선택: 상대 방해에 돈을 쓰거나 투자금을 보존.
- 주의: 이동 제한 중에도 UI 닫기와 해제 조작 허용. 반복 표적화 방지용 면역 시간 필요. 경매 참여를 장시간 막는 효과는 피함.

## 4. 회사 기여 알바
- 역할: 자금이 적은 플레이어의 능동적 수입원, 회사와 주식 시장의 연결.
- 초기안: 짧은 운반·정리 작업 완료 → 고정 급여 → 해당 회사의 다음 변동 상승 확률에 제한된 기여.
- 핵심 선택: 작업하는 동안 거래와 경매 기회를 포기.
- 주의: 확정 주가 상승으로 만들지 않음. 라운드별 기여 상한과 반복 보상 제한으로 한 회사 몰아주기 방지. 기존 주가 결정 방식과 결합 가능성 확인 필요.

## 5. 경매장 점프 코스
- 역할: 이동 구간에 긴장감과 구경하는 재미 추가.
- 초기안: 안전한 일반 길과 짧은 점프 지름길을 병행. 실패하면 가까운 출발점으로 복귀.
- 핵심 선택: 안전하게 이동하거나 실패 위험을 감수하고 시간 절약.
- 주의: 유일한 경매 진입로로 만들면 투자 판단보다 조작 실력이 승패를 좌우할 수 있음. 충돌을 이용한 길막과 경매 시작 전 도착 시간을 점검.

## 6. 재기 지원 이벤트
- 역할: 하위권이 다음 선택을 할 수 있도록 기회 제공.
- 초기안: 중반 특정 시점, 일정 자산 격차 이상의 최하위에게 1회 한정 지원. 즉시 현금 또는 지원 알바 선택.
- 핵심 선택: 지원 이후 투자·입찰·노동으로 복귀 경로 선택.
- 주의: 현금이 아닌 현금·주식·부동산·부채를 반영한 순자산으로 판정. 일부러 꼴찌가 되는 이득과 지원금으로 직접 승리가 결정되는 상황을 방지.

## 권장 도입 순서
1. 알바와 조건부 재기 지원: 부족한 자금에서 다시 행동할 수 있는 경로 확보.
2. 집문서와 간단한 상점: 투자·견제에 현금을 쓰는 선택 확장.
3. 대출·청산: 자금 유입과 지출을 확인한 뒤 위험 구조 추가.
4. 점프 지름길: 경제 규칙과 분리해서 이동 재미 검증.

## 이미지 제작 기록
- 방식: 기본 내장 image_gen, 아이디어별 개별 생성.
- 공통 프롬프트: Buy Bid Blow의 스타일화된 low-poly Unity 3D 게임플레이 콘셉트. 에메랄드 벽, 황동과 금 장식, 목재, 붉은 카펫의 빈티지 경매장. 정장을 입은 귀여운 동물 캐릭터, 금색 테두리의 짙은 녹색 UI. 간결한 한국어 제목. 실제 구현 화면이 아닌 제안 시안.
- 개별 프롬프트: 집문서와 반복 임대료 / 납부 만기와 자산 강제 매각 / 목줄과 해제 도구 상점 / 목재 운반 알바와 급여·제한된 확률 기여 / 안전 경로와 점프 지름길 / 하위권의 1회 조건부 재기 지원.
