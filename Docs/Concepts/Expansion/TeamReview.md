# Buy Bid Blow — 콘텐츠 확장 회의

2026-10-27 · 제안 검토용 / 확장 기능 미구현

## 현재 구현 규칙

3~6명 · 시작 $200 / 주식 0주 · 총 13라운드 · 일반 60초 / 경매 120초 · 경매 2·6·10R · 총 기본 16분

- 최종 현금 + 보유 주식 평가액으로 순위. 동점이면 주식 총수 우선.
- 회사별 재고 = 인원 × 5 + 5주. 주가 하한 $5.
- 공개 경매 60초 → 비공개 경매 30초 → 자유 거래 30초. 현재 정보만 판매, 최소 입찰 $1.
- 하락 베팅: 현재 주가 1주분 참가금, 하락 시 원금 포함 2배, 마감 전 취소 가능.
- 미래 주가는 시작 시 전부 생성. 상승 확률 Straw 35% / Timber 50% / Brick 75%.

## 01 · 부동산

세 가지를 모두 넣는 결정이 아니라, 기본 방식을 고르는 대안 비교입니다. 현재 방향은 A이며 구현 전입니다.

### P-A · 종료 시 감정가 정산

**상태:** 현재 채택 방향 · 미구현

- **플레이:** 경매 낙찰 → 집문서 보유 → 경기 종료 시 무작위 가치로 환산. 대부분 큰 값어치를 갖는 방향.
- **기대 재미:** 기존 경매를 활용하고 투자금을 묶는 선택, 마지막 공개의 긴장감을 만듦.
- **우려·보완점:** 감정가 운이 거래 성과를 압도할 수 있음.
- **회의에서 결정:** 감정가 범위·분포 공개 여부 / 등장 횟수 / 기존 정보 슬롯 대체 또는 추가
- **예상 제작 부담:** 중 — 상대 추정, 공수 확정 아님

### P-B · 청약형 룰렛

**상태:** 대안

- **플레이:** 금액을 투자할수록 부동산에 당첨될 확률이 증가.
- **기대 재미:** 여러 명이 같은 매물을 두고 경쟁하고 추첨 장면을 함께 즐김.
- **우려·보완점:** 자금이 많은 사람이 확률도 독점할 수 있고, 미당첨 손실에 불만이 생길 수 있음.
- **회의에서 결정:** 고정 가치 또는 범위 공개 / 개인 투자 상한 / 미당첨금 환불 여부
- **예상 제작 부담:** 중~높음 — 상대 추정, 공수 확정 아님

### P-C · 임대료형 집문서

**상태:** 대안

- **플레이:** 보유한 집문서가 라운드마다 일정 수입을 지급.
- **기대 재미:** 안정 수입과 주식 투자를 비교하는 전략 제공.
- **우려·보완점:** 조기 구매자가 누적 수익에서 유리하고 후반 매물의 매력이 낮음.
- **회의에서 결정:** 지급 시작 시점 / 남은 지급 횟수 / 최종 잔존 가치
- **예상 제작 부담:** 중 — 상대 추정, 공수 확정 아님

## 02 · 회사 기여 알바

플레이어는 작업 시간과 거래·경매 기회 사이에서 선택합니다. 급여와 확률 기여의 크기는 별도 조정합니다.

### J-A · 회사별 작업

**상태:** 제안

- **플레이:** Straw는 짚 포장, Timber는 목재 분류, Brick은 벽돌 쌓기.
- **기대 재미:** 회사별 개성이 분명하고 행동을 직관적으로 이해.
- **우려·보완점:** 세 작업의 제작량과 난이도 차이가 커질 수 있음.
- **회의에서 결정:** 작업 시간 / 급여 / 난이도 통일 기준 / 라운드 기여 상한
- **예상 제작 부담:** 중~높음 — 상대 추정, 공수 확정 아님

### J-B · 풍선 펌프

**상태:** 대안

- **플레이:** 펌프로 풍선에 바람을 넣어 목표량을 달성.
- **기대 재미:** 진행도를 쉽게 읽고 우스운 상황 연출 가능.
- **우려·보완점:** 단순 연타는 피로하고 회사 사업과의 연결이 약함.
- **회의에서 결정:** 연타 또는 타이밍 방식 / 과압 실패 / 회사별 외형
- **예상 제작 부담:** 중 — 상대 추정, 공수 확정 아님

### J-C · 기도

**상태:** 대안

- **플레이:** 회사 상징물 앞에서 짧은 기도를 완료해 기여.
- **기대 재미:** 조작이 쉬우며 여러 플레이어가 모인 장면이 재밌음.
- **우려·보완점:** 대기만 하는 활동으로 느껴지기 쉬움.
- **회의에서 결정:** 즉시 급여 제공 여부 / 유지 시간 / 반복 제한
- **예상 제작 부담:** 낮음~중 — 상대 추정, 공수 확정 아님

### J-D · 회전 장치 밀기

**상태:** 대안

- **플레이:** 원형 손잡이를 밀어 프로펠러나 회사 기계를 가동.
- **기대 재미:** 이동 자체를 작업으로 사용하고 협동 장면 생성.
- **우려·보완점:** 충돌과 길막, 카메라 회전 피로 가능.
- **회의에서 결정:** 개인 또는 공동 작업 / 기여도별 보상 / 카메라 처리
- **예상 제작 부담:** 중~높음 — 상대 추정, 공수 확정 아님

## 03 · 파티 아이템 상점

투자 외의 현금 사용처를 만들되, 상대의 경기 참여를 장시간 막지 않도록 설계합니다.

### S-A · 목줄

**상태:** 제안

- **플레이:** 다른 플레이어를 지정해 짧게 이동을 방해.
- **기대 재미:** 추격·도주·견제와 복수에서 파티 장면 생성.
- **우려·보완점:** 경매 참여 차단과 특정 플레이어 연속 괴롭힘 위험.
- **회의에서 결정:** 사거리 / 지속 시간 / 해제 도구 / 피격 후 면역 / 사용 제한
- **예상 제작 부담:** 중~높음 — 상대 추정, 공수 확정 아님

## 04 · 도박성 장치

가챠는 아이템 공급, 슬롯·룰렛은 현금 위험 선택이라는 역할을 구분합니다. 기존 하락 베팅 및 부동산 청약과 중복 확인이 필요합니다.

### G-A · 아이템 가챠

**상태:** 제안

- **플레이:** 돈을 내고 무작위 아이템을 획득.
- **기대 재미:** 발견과 수집의 재미, 반복 경기의 변화.
- **우려·보완점:** 대응 도구도 운에 의존하면 불합리하게 느껴질 수 있음.
- **회의에서 결정:** 확률·품목 공개 / 직접 구매 병행 / 중복 처리
- **예상 제작 부담:** 중 — 상대 추정, 공수 확정 아님

### G-B · 슬롯머신

**상태:** 제안

- **플레이:** 금액을 걸고 무작위 결과에 따라 배당.
- **기대 재미:** 규칙이 단순하고 짧게 참여 가능.
- **우려·보완점:** 주식보다 유리하면 투자 게임의 중심을 대체.
- **회의에서 결정:** 배당·확률 / 횟수 상한 / 참여 시간 / 게임머니만 사용
- **예상 제작 부담:** 중 — 상대 추정, 공수 확정 아님

### G-C · 일반 룰렛

**상태:** 제안

- **플레이:** 결과나 구역을 골라 베팅하고 추첨.
- **기대 재미:** 다 같이 결과를 보는 반응과 긴장감.
- **우려·보완점:** 하락 베팅·슬롯·청약과 역할이 겹침.
- **회의에서 결정:** 장치 통합 여부 / 최대 베팅 / 배당 / 동시 참여
- **예상 제작 부담:** 중 — 상대 추정, 공수 확정 아님

## 05 · 개인미션

기존 행동을 다르게 선택하도록 유도하는 보조 목표입니다.

### M-A · 무작위 개인 목표

**상태:** 제안

- **플레이:** 각자 다른 목표를 받고 달성하면 보상. 예: 두 회사에서 작업 완료, 특정 종목 일정 수량 보유.
- **기대 재미:** 사람마다 다른 행동을 하며 블러핑과 재플레이성 강화.
- **우려·보완점:** 목표 운과 난이도 차이, 보상만 얻는 무의미한 반복 거래 가능.
- **회의에서 결정:** 목표 비공개 여부 / 교체 기회 / 보상액 / 달성 가능성
- **예상 제작 부담:** 중 — 상대 추정, 공수 확정 아님

## 06 · 청산과 회사 위험

대출 청산은 개인의 부채 문제이고, 상장폐지는 회사 위험입니다. 별개 규칙으로 검토합니다.

### L-A · 대출·강제 청산

**상태:** 제안

- **플레이:** 대출로 투자금을 확보하고, 만기 미상환 시 보유 자산을 강제 매각.
- **기대 재미:** 현금 운용과 위험 관리에 깊이 추가.
- **우려·보완점:** 하위권의 부채 악화와 규칙 학습 부담.
- **회의에서 결정:** 한도 / 이자 / 만기 / 경고 / 매각 순서·가격 / 잔여 부채
- **예상 제작 부담:** 높음 — 상대 추정, 공수 확정 아님

### L-B · 상장폐지

**상태:** 제안

- **플레이:** 조건에 따라 회사 거래를 종료하고 주식 가치를 정산.
- **기대 재미:** 분산 투자와 회사 위험에 긴장감 부여.
- **우려·보완점:** 예고 없는 손실이 크고 세 회사 중 하나가 사라지면 시장이 단조로워짐.
- **회의에서 결정:** 발생 조건·사전 경고 / 유예 / 잔여 가치 / 신규 종목 여부
- **예상 제작 부담:** 높음 — 상대 추정, 공수 확정 아님

[참고 시안](C:/훈련생폴더/3. 유니티/Buy_Bid_Blow/Docs/Concepts/Expansion/02_liquidation.png) — 부채 상환을 위한 매각 시안. 상장폐지를 표현한 화면은 아닙니다.

## 07 · 랜덤 이벤트

역전 기회와 앞선 플레이의 가치를 함께 고려합니다.

### E-A · 1등 자산 재분배

**상태:** 제안

- **플레이:** 현재 1등 자산 일부를 다른 플레이어에게 균등 분배.
- **기대 재미:** 선두 독주를 빠르게 완화.
- **우려·보완점:** 잘한 플레이를 벌주는 느낌, 고의 2등 유지 유도.
- **회의에서 결정:** 순자산 기준 / 분배 대상에 1등 포함 여부 / 비율 / 사전 예고
- **예상 제작 부담:** 중 — 상대 추정, 공수 확정 아님

### E-B · 꼴등 지원금

**상태:** 제안

- **플레이:** 조건을 충족한 최하위에게 지원금 지급.
- **기대 재미:** 다음 거래에 참여할 기회를 제공하고 탈락감 완화.
- **우려·보완점:** 고의 꼴찌와 지원금이 승패를 직접 결정하는 상황 가능.
- **회의에서 결정:** 순자산·격차 기준 / 지급 시점 / 1회 제한 / 금액
- **예상 제작 부담:** 낮음~중 — 상대 추정, 공수 확정 아님

### E-C · 주식 버닝

**상태:** 제안

- **플레이:** 특정 구간에 회사 주가 상승 확률을 대폭 높임.
- **기대 재미:** 거래가 집중되는 축제 구간과 긴장감 제공.
- **우려·보완점:** 기존 대량 보유자가 유리하며 확정 정보와 충돌 가능.
- **회의에서 결정:** 사전 공지 / 대상 회사 / 적용 구간 / 확률 상한
- **예상 제작 부담:** 중~높음 — 상대 추정, 공수 확정 아님

## 08 · 경매장 점프 코스

경제 규칙과 분리해서 이동 재미를 테스트할 수 있습니다.

### T-A · 점프 지름길

**상태:** 제안

- **회의에서 결정:** 실패 복귀 위치 / 일반 길 소요 시간 / 충돌 / 도착 여유
