# 추가 화면 시안 v1

이번 결과는 화면 설계와 이미지 시안입니다. Unity 씬·프리팹·게임 로직은 변경하지 않았습니다. Concepts에 6개 보드, 보드마다 4개 화면/상태를 묶습니다. 이미지 속 수치는 예시이며 생성 이미지의 문구는 최종 구현 시 아래 명세와 대조합니다.

## 공통 디자인

- 어두운 청록 반투명 패널, 절제된 황동 테두리, 크림색 텍스트, 나무·황동 버튼. 선택한 버튼만 밝게 강조.
- 정보 문서는 기존 HowToPlay·수첩과 연결되는 아이보리 종이 사용.
- 키보드 조작: 방향키 선택/조절, Enter 확인, Esc 뒤로. 실제 게임 키 설정과 최종 통합 시 정합성 확인.
- 팝업은 중앙, 개인 알림은 왼쪽 위 자산 아래, 라운드 배너는 상단 중앙. 아래 경매 입력 패널과 겹치지 않도록 함.
- 작은 오류/확인 팝업: 1920×1080 기준 약 640×340. 접속 진행 팝업: 약 720×400. 설정: 약 900×680. 결과: 약 1440×800. 최종 크기는 실제 텍스트 길이에 따라 검수.
- 팝업 뒤 딤은 약 60%, 토스트에는 전체 화면 딤을 쓰지 않음. 오류는 붉은색만으로 설명하지 않고 아이콘·문구를 함께 표시.
- 입력 차단 팝업과 비차단 토스트 구분. Esc 메뉴를 열어도 온라인 경기 시간은 계속됨.

## 내용과 정보 공개 기준

- 결과: 순위, 닉네임, 총자산, 현금, 주식 평가액, 보유 주식 수. 총자산 동점 시 보유 주식 수, 이것도 같으면 공동 순위. 경기 종료 후 세부 정산 수치를 전원에게 공개하는 것은 현재 시안의 제안이며 실제 규칙·네트워크 공개 범위 확정 시 조정 가능.
- 로비 복귀: 호스트가 진행하는 흐름을 가정한 시안. 개인 버튼 활성 조건은 병합 후 구현에서 확정.
- 시작 대기: 전원이 준비되기 전에는 시작 카운트다운을 표시하지 않음.
- 접속 중 취소, 접속 실패 재시도 지원을 가정한 디자인. 재접속·관전·호스트 승계 기능은 제안하지 않음.
- 연결 끊김/호스트 종료: 이유와 메인 메뉴 복귀만 제공. 복구를 약속하는 카운트다운을 넣지 않음.
- 공개 낙찰은 닉네임·가격 공개. 비공개 결과는 본인 성공/실패와 본인 제출금만 표시하며 타인 결과·금액은 숨김.
- 정보 획득 팝업은 개인 화면. 두 라운드×두 회사, 실제 종가 기준 상승·하락·보합. 상승 진한 빨강, 하락 진한 파랑, 보합 흑연.
- 베팅 $40 성공 시 총 $80 지급, 순이익 $40. 실패 시 참가금 $40 손실.
- 거래 실패는 전체 거절. 토스트는 실패 이유를 짧게 표시하고 입력 영역을 가리지 않음.
- 이탈 알림에는 미확정된 자산 처리나 경기 중단 정책을 적지 않음.
- 크레딧은 실제 출처가 입력될 자리만 표시. 제공되지 않은 제작자·라이선스는 임의 작성하지 않음.

## 공통 컴포넌트로 재사용할 구조

1. 공통 모달: 아이콘·제목·설명·선택적 상세 정보·버튼 1~2개.
2. 접속 진행 모달: 공통 모달 + 진행 표시 + 취소.
3. 설정 패널: 탭 + 설정 행 + 하단 버튼.
4. 문서 패널: 종이 + 제목 + 스크롤 콘텐츠 + 닫기.
5. 개인 토스트: 상태 아이콘 + 제목 + 1~2줄 요약.
6. 라운드 배너: 라운드/상태 + 짧은 설명.
7. 결과 패널: 순위 표 + 내 행 강조 + 동점 기준 + 복귀 안내.

제작 도구는 imagegen 내장 도구. 최종 프롬프트와 보드별 조건은 ConceptPrompts.json에 저장합니다.

## 시안 검수 메모
04_RoundAuction_v2.png가 최신 라운드 보드입니다. 기존 04는 비교용 초안입니다. 생성 이미지의 일부 배경 HUD는 원본 참조의 입찰 예약금과 시간을 그대로 포함하므로 상태별 최종 수치로 해석하지 않습니다. 비공개 경매 종료 시 실제 남은 라운드 시간은 02:00이며 이미지의 03:00은 구현 시 수정 대상입니다. 베팅 정산 토스트는 라운드 마감 정산 시 표시하고, 이미지의 경매 진행 배경은 위치 설명용입니다. 메뉴의 세로 항목 선택은 ↑↓로 구현합니다. 결과 세부 자산의 전원 공개 여부와 호스트 복귀 버튼 활성 조건은 확정 전 제안입니다.
