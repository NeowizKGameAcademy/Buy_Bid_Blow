Each FBX contains LOD0 and LOD1. One metre units; floor-centred pivot; Unity front is +Z.
LOD screen-height thresholds: 0.14 (LOD0), 0.018 (LOD1), culled below 0.018.
Shared 1024x1024 base-colour, metallic/smoothness and normal atlases.
Glass uses a separate 512x512 smudge metallic/smoothness mask.
Metallic is red; smoothness is alpha. Base colour is sRGB; the mask is linear.
Each opaque prop is one mesh/material. Cabinet glass is a separate transparent mesh shared by both LODs.
Simple box collider per prefab. No runtime behaviour, moving doors, or interaction scripts.
Models are supplied separately; they have not been placed into the hall.

Unity vertex counts include UV/normal splits; see BBB_Lounge_Accessories_Unity_Budget.txt.
Blender topology counts are in BBB_Lounge_Accessories_Budget.json.
Validated: Unity import/build, material rendering including front-facing leaflets, metre scale,
floor pivot, LOD references, and zero-area triangle cleanup. No target-device FPS benchmark.
